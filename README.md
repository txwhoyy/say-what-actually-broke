One honest error message for an upload that died at 99%: the connection dropped, not the user's file. It's funny because the progress bar gets caught in the lie — the 99% was real, but the bar was just pretending everything was fine to keep the user calm. The line names the real failure in plain words and tells the user exactly what to do next: reconnect and try again.

## Run it

```sh
node main.ts
```
